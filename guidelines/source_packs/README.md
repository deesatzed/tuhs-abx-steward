# Source packs (not runtime schema)

These JSON files are the TUH-Inc. Empiric Antimicrobial Therapy Recommendations (ver 2025-04-02) extract from `deesatzed/deterministic_knowledge_retrieval`. They are documentation of the source extract, not the v3 runtime infection schema loaded by `lib/guideline_loader_v3.py`.

Runtime packs live in `guidelines/infections/*.json`.

`infection_cap.json` is kept here only as documentation. Steward `pneumonia.json` already covers CAP (ward/ICU) categories, so it was not converted into a new v3 infection file.
